🎞️ Storyboard v3: The Relay

A connected story, one handoff per station. The film is blocked until this storyboard is approved.

⏳ Status: awaiting approval. Nothing has been rendered, voiced or subtitled for this version.

✅ To approve, reply "approved". 🔁 To change, name the scene number and what to change.

🧭 1. Approaches considered (brainstorming)

ApproachHow it worksVerdict
A · Independent facts (v1, v2)Each station is a separate fact with its own narration.❌ Rejected. The viewer has nothing to link the stations with. See the changelog.
B · Walk-through tourErdem walks the palace and describes each station.❌ Rejected. A tour is still seven facts in a row.
C · Linked relay (chain story)Each station's object hands the film to the next station. The seven items form one cause-and-effect chain.✅ Recommended. This is the standard chain-linking technique, and it is what the story below uses.

🔗 2. The chain

🧭 01 PLAN · the compass needle ➜ 🏛️ 02 SETTING · the red arrow ➜ 🎥 03 MOVE · the camera ➜ ⚪ 04 CLAY · the clay ball ➜ 🔍 05 CHECK · the approved ball ➜ 📝 06 PROMPT · the words ➜ 🎬 07 RENDER · the finished film ➜ 🧠 the viewer, remembering

🛠️ 4. How it will be made (after approval)

  1. 🎙️ Narration: the approved text, read with the voice model. Chapter durations come from a full decode of the audio, not from file headers.
  2. 🖼️ Visuals: the station images and clips already generated, plus the palace overview and the clay shot.
  3. 💬 Subtitles: word by word, timed to each scene.
  4. 🎞️ Stitch: HyperFrames composition, checked with npm run check, with frame snapshots reviewed before render.
  5. 📜 Versioned: a new changelog entry, and the approval recorded in STORY.md.
