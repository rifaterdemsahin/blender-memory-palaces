🚀 Leverage it: a palace for Erdem

🧑‍💻 Erdem can reuse this palace for any list of seven things: exam topics, client points, presentation slides, vocabulary, or code concepts. Only the list changes. The route, the pictures, the voices and the videos are rebuilt from it.

🎯 1. Pick seven things worth remembering

  • 📚 Study: seven key ideas from one chapter.
  • 🎤 Talk: the seven points of a presentation, in order.
  • 🗣️ Language: seven words or phrases you keep forgetting.
  • 🧾 Work: the seven steps of a process you run often.

✏️ Write each one as a short keyword plus one meaning sentence, like the palace does (for example: PLAN · "Plan the shot: hero, setting, move, look").

🛠️ 2. Rebuild it in three steps

  1. ✏️ Edit the list. Change the ITEMS list at the top of memory-palace/build_palace.py (keyword, station name, meaning, position), and the STATIONS list in memory-palace/generate_assets.py (image, video and narration text, with extreme scenes that are easy to remember).
  2. 🧱 Build the 3D palace in Blender: blender -b --python memory-palace/build_palace.py
  3. 🎨 Generate the media (needs your own DeepInfra key in your shell only, never in a file): 
    export DEEPINFRA_API_KEY=...        # your shell only
python3 memory-palace/generate_assets.py --dry-run   # cost plan, no spend
python3 memory-palace/generate_assets.py --all       # images, videos, narration
python3 memory-palace/build_site.py                  # rebuild the page

📅 4. A 7-day plan

📆 Day🎯 Task
1️⃣Pick the seven items and write the keyword and meaning for each.
2️⃣Build the palace and walk it once with the walkthrough.
3️⃣Practise: tap each station, look, listen, close your eyes, recall it.
4️⃣Recall all seven in order, with no notes. Note which ones you missed.
5️⃣Strengthen the missed ones with a sharper picture, then recall again.
6️⃣Recall in reverse order, to check the route is solid.
7️⃣Recall all seven, then use them in the real task.

✅ 5. How to know it is working

📈 Track the number of items recalled correctly on each day. If the count rises over the week, the palace is working for you. If it does not, make the images more extreme and the narration shorter.
